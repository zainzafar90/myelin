# Myelin lessons

Approved lessons only. The first 5 bullets are injected every session, so keep
the best ones first. Mined candidates will arrive via the nightly miner
(Phase 2). Until then, add lessons by hand after any correction.

- Prefer CSS variables over inline style edits so the user can tune without code changes.
- Never claim done without running the project's test/build — the Stop gate will hold you to it.
- Any "skip it for now" gets a debt.md entry at that moment, not later.
- When delegating to Codex, the brief must name exact files and stop conditions.
- Centralize configuration; the user rejects scattered, ad-hoc config.
